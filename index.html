process-media

Rename and process photos and videos from their EXIF capture date.

A small CLI tool. Ships as a Debian package.

v2.0.1 Python 3.11+ MIT License
Install Instructions GitHub Documentation

Installation

Available natively for Debian trixie and Ubuntu 25.04+ (supports both amd64 and arm64).

1. Trust the signing key

curl -fsSL https://llavaud.github.io/process-media/apt/conf/gpg.key \
    | sudo gpg --dearmor -o /usr/share/keyrings/process-media-archive-keyring.gpg

2. Add the repository

echo "deb [signed-by=/usr/share/keyrings/process-media-archive-keyring.gpg] \
https://llavaud.github.io/process-media/apt stable main" \
    | sudo tee /etc/apt/sources.list.d/process-media.list

3. Install

sudo apt update
sudo apt install process-media

Not on Debian/Ubuntu? Check out the source installation guide.

Features

  • Smart renaming: Uses EXIF capture date, gracefully falls back to filename patterns.
  • Pipelines: Multiple output pipelines including resize, rotate, strip metadata, re-encode, and thumbnail generation.
  • Robustness: Parallel processing, atomic writes, and safe Ctrl+C handling.
  • Configurable: Uses a single YAML configuration file with strict Pydantic v2 validation.
